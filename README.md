# Worktree

WBS 문서를 트리·칸반·작업 네트워크·간트 차트로 살펴보는 Windows 데스크톱 앱입니다. 여러 문서를 탭으로 열고 작업의 상태·일정·완료 기준을 확인할 수 있습니다.

현재는 **읽기 전용**입니다. 문서 작성과 수정은 텍스트 편집기에서 진행하며 Worktree는 저장된 내용을 읽어 표시합니다.

## 설치 및 실행

1. [최신 릴리즈](https://github.com/DevPumpkin0113/worktree/releases/latest)에서 `Worktree_버전_x64-setup.exe`를 다운로드합니다. `Source code` 파일은 설치 프로그램이 아닙니다.
2. 설치 프로그램을 실행하고 안내에 따라 설치합니다.
3. 설치된 Worktree를 실행합니다. 연결된 `.wbs` 파일을 더블클릭해도 열 수 있습니다.

배포 대상은 Windows x64입니다. WebView2 런타임이 필요하며 일반 사용자는 Node.js나 Rust를 설치할 필요가 없습니다. 별도의 로컬 서버를 실행하지 않아도 됩니다.

## 처음 사용하기

1. [예제 문서](examples/Visualization-demo.wbs)를 다운로드하거나 아래 작성 방법에 따라 문서를 준비합니다.
2. 앱 우측 하단의 **+** 버튼으로 파일을 선택합니다. 파일을 앱 창으로 끌어 놓아도 됩니다.
3. 도구 모음의 보기 아이콘을 선택합니다. 아이콘 위에 마우스를 올리면 이름을 확인할 수 있습니다.
4. 작업을 선택해 상세 정보를 확인합니다.

여러 파일을 열면 하단에 문서 탭이 생깁니다. 탭으로 문서를 전환하고 각 탭의 닫기 버튼으로 닫습니다. 이미 열린 파일을 다시 열면 해당 탭으로 이동합니다.

## 보기와 탐색

| 보기 | 확인할 수 있는 내용 |
|---|---|
| 트리 | 상위·하위 작업 구조. 그룹을 펼치거나 접어 탐색합니다. |
| 칸반 | 시작 전·진행 중·막힘·완료 상태별 작업 목록 |
| 작업 네트워크 | 선행·후속 작업의 연결. 노드를 선택하면 관련 경로가 강조됩니다. |
| 간트 차트 | 세로 작업 목록·가로 날짜 축의 일정. 일·주 단위로 전환할 수 있습니다. |

검색창에서는 작업 ID·작업명·담당자로 찾고, 상태 필터로 목록을 좁힐 수 있습니다. 검색은 원본 ID와 화면에 표시된 ID를 모두 지원합니다.

작업 네트워크와 간트 차트의 빈 공간을 마우스로 잡아 끌면 화면을 이동할 수 있습니다. 이 동작으로 작업 일정이나 문서 내용이 바뀌지는 않습니다. 작업 네트워크에서는 상세 버튼 또는 노드 더블클릭으로 상세를 엽니다.

간트 차트는 입력된 일정만 표시하고 미정 작업을 별도로 안내합니다. 마일스톤은 마름모로 표시됩니다. 작업 네트워크의 단계는 연결의 깊이이며 착수 가능 여부를 뜻하지 않습니다.

## 작업 상세와 설정

작업 상세에서 담당자·상태·일정·예상 공수·완료 기준과 연결된 작업을 확인합니다. 연결 작업을 누르면 해당 작업의 상세로 이동합니다.

타이틀바 오른쪽의 **설정 아이콘**에서 다음을 변경할 수 있습니다.

- **상세 정보 표시**: 우측 사이드 패널 또는 모달. 기본은 우측 사이드 패널이며 선택한 작업은 목록·차트에 강조됩니다.
- **ID 구분자**: `W001` 또는 `W-001`처럼 표시합니다. 문서에 접두어가 있으면 `OBS001` 또는 `OBS-001`로 표시합니다. 원본 ID와 작업 연결은 바뀌지 않습니다.

설정은 변경 즉시 적용·저장되며 재실행 후에도 유지됩니다. 설정 창 우측 상단 X 또는 바깥 배경을 눌러 닫습니다. 작업 상세는 X·Esc로 닫고 모달 방식에서는 바깥 배경 클릭으로도 닫을 수 있습니다. 앱 버전은 설정 창 하단에서 확인합니다.

## WBS 문서 작성 및 수정

**`.wbs` 파일은 `.md`와 같은 Markdown 형식**을 사용합니다. 일반 텍스트 편집기로 작성하되 Worktree가 읽을 수 있도록 정해진 WBS 양식을 지켜야 합니다. 모든 Markdown 문서가 자동으로 시각화되는 것은 아닙니다.

1. [복사용 템플릿](templates/template.wbs)을 다운로드해 **프로젝트명.wbs**로 저장합니다. 예: `MyProject.wbs`.
2. 메타데이터의 `title`, `project_id`, `updated`와 문서 제목을 수정합니다.
3. `작업 목록` 표의 예시 행을 실제 작업으로 바꿉니다. 표의 열 이름과 순서는 유지합니다.
4. ID는 문서 안에서 고유하게 지정하고 `상위 ID`로 계층을, `선행 작업`으로 연결을 지정합니다. 미정 값은 `-`로 입력합니다.
5. UTF-8로 저장하고 Worktree에서 엽니다.

상세한 필드 규칙·상태·날짜·접두어 작성법은 [WBS 작성 가이드](templates/README.md)를 참고하세요. ID 접두어는 선택 항목이며 생략하면 `W`를 사용합니다.

외부 편집기에서 원본을 저장하면 활성 문서를 약 1.5초 간격으로 확인해 자동 갱신합니다. 다른 탭의 문서는 탭 선택 시 확인합니다. 즉시 다시 읽으려면 타이틀바의 **새로고침 아이콘**을 누르세요.

## 지원 범위

- UTF-8 인코딩의 최대 5MB 문서를 지원합니다.
- 파일 선택과 안내는 `.wbs`를 기준으로 제공합니다. 기존 `.md` 문서도 같은 WBS 양식을 따를 경우 읽을 수 있습니다.
- 일정과 공수가 미정이면 임의로 추정하지 않습니다. 공수 기준 진척도를 계산할 수 없으면 `산정 불가`로 표시합니다.
- 앱에서 작업을 작성·수정하거나 일정을 끌어 변경하는 기능은 제공하지 않습니다.

## 문제 해결

**파일을 더블클릭해도 Worktree가 열리지 않아요.**

파일의 연결 프로그램에서 Worktree를 선택하세요. 설치 프로그램은 `.wbs` 연결을 등록하지만 기본 앱 선택은 Windows 설정을 따릅니다. 단독 exe 실행은 파일 연결을 등록하지 않습니다.

**문서를 열 때 오류가 나요.**

[작성 가이드](templates/README.md)와 비교해 작업 표의 열 이름·순서, ID 중복, 상위 ID·선행 작업의 참조와 순환 여부를 확인하세요. 파일 인코딩과 크기도 확인합니다.

**수정한 내용이 보이지 않아요.**

편집기에서 원본 파일을 저장했는지 확인하고, 해당 문서 탭을 선택한 뒤 새로고침을 누르세요.
