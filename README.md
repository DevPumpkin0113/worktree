# Worktree

WBS 문서를 트리·칸반·작업 네트워크·간트 차트로 확인하는 Windows 앱입니다.

## 설치 및 실행

1. [최신 릴리즈](https://github.com/DevPumpkin0113/worktree/releases/latest)에서 `Worktree_버전_x64-setup.exe`를 다운로드해 설치합니다.
2. Worktree를 실행하거나 연결된 `.wbs` 파일을 더블클릭합니다.

Windows x64와 WebView2 런타임이 필요합니다. 설정 → 앱 정보에서 새 버전을 확인하고 다운로드·설치할 수 있습니다. 앱 시작 시 자동 확인을 끌 수도 있습니다. 0.4.0 사용자는 설치 프로그램으로 한 번 업데이트해 주세요.

## 사용 방법

- 우측 하단 **+**로 프로젝트 폴더를 엽니다. 폴더 하나가 하단 **프로젝트** 탭 하나가 되며, 좌측 탐색기에서 폴더를 접고 펼치며 `.wbs` 파일을 선택합니다. 보드·목록·인사이트는 선택한 WBS를 기준으로 표시합니다. 탐색기 아래 경계를 위아래로 끌어 높이를 조절할 수 있습니다.
- 프로젝트 탭을 끌거나 Alt+Shift+←/→로 순서를 바꿉니다. **최근**에서 최근 프로젝트 12개를 다시 열고, 재실행하면 최대 40개 프로젝트와 프로젝트별 마지막 선택 문서·보기 설정을 복원합니다.
- 폴더나 WBS 파일을 드래그 앤 드롭으로 열 수도 있습니다. WBS 파일을 직접 열면 해당 파일의 상위 폴더를 프로젝트로 엽니다. 빈 폴더도 열 수 있으며 파일 추가·삭제 후 좌측 상단 새로고침으로 목록을 갱신합니다.
- 보기 아이콘으로 **트리·칸반·작업 네트워크·간트 차트**를 전환합니다.
- 검색과 담당자·상태 필터로 작업을 찾고, 작업을 선택해 상세 정보를 확인합니다.
- 트리 그룹 요약과 그룹의 **상세** 버튼에서 하위 일정·공수·진척도를 확인합니다. 미정이 있으면 일정 범위와 공수 소계에 함께 표시합니다.
- 작업 네트워크·간트 차트의 빈 공간을 마우스로 끌어 화면을 이동합니다.
- 우측 상단 설정에서 **상세 표시 방식**과 **ID 하이픈 표시**를 변경합니다. 변경 즉시 저장됩니다.

현재는 **읽기 전용**입니다. 외부 편집기에서 원본을 수정·저장하면 자동 갱신되며, 좌측 상단 새로고침 버튼으로 다시 읽을 수도 있습니다. 같은 문서 갱신 시 열어 둔 상세·스크롤·그룹 접힘을 유지하며, 삭제된 작업의 상세는 닫습니다.

문서 오류는 하단 오류 버튼을 눌러 원인·관련 원문·수정 예시를 확인합니다. 위치는 원본 행과 문자 기준 열 범위로 표시하며, 정확한 열을 확인할 수 없으면 행만 표시합니다.

상단 작업 카드는 완료 수 / 전체 수를, 진행률 게이지는 일반 작업의 완료 개수 비율을 표시합니다. 그룹·마일스톤은 게이지 계산에서 제외합니다. 공수 기준 진척도는 별도 지표입니다.

## 설정 파일

설정은 `%LOCALAPPDATA%\Worktree\settings.json`에 저장됩니다. 기존 설정은 첫 실행 시 자동으로 이전됩니다. 직접 편집하려면 앱을 종료한 뒤 변경하고 다시 실행하세요. 최근 프로젝트와 열린 프로젝트·문서 정보는 같은 폴더의 `session.json`에 별도로 저장됩니다. 손상된 세션 오류가 나면 앱 종료 후 해당 파일을 다른 곳으로 옮겨 보존하고 다시 실행하세요.

## 문서별 공수 사용 (Worktree 0.13.0 이상)

문서 맨 위 `---` 메타데이터에 `use_effort: true` 또는 `use_effort: false`를 작성합니다. 생략하면 기존 문서와 같이 true입니다. 따옴표 없이 소문자 true·false만 허용합니다.

false이면 공수 기준 진척도 카드, 그룹의 공수·공수 가중 진척도, 작업 상세의 공수, 상태 표시줄의 공수 미정 안내를 숨깁니다. 작업 개수 기준 진행률은 계속 표시합니다. 문서 전환과 새로고침 시 해당 문서의 값을 적용합니다.

표의 예상 공수(h) 열과 기존 검증 규칙은 유지합니다. 미사용 문서는 task 공수에 `-`, group에 `-`, milestone에 `0`을 작성하면 됩니다. 기존 숫자는 보존합니다. schema_version은 1을 유지하며 이전 앱은 이 항목을 무시하고 공수를 계속 표시하므로 표시 제어에는 0.13.0 이상이 필요합니다.
