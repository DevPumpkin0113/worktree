# 에픽 계층

TASK028에서 앱 0.34.0 / CLI 0.6.0 개발 범위로 도입하고, TASK029에서 이슈 명칭과 에픽 직속 소속을 확장한다. UI 상세 배치는 사용자 확인 후 조정한다.

상단 생성 동작은 `+ 추가` 메뉴 하나에 이슈·마일스톤·에픽 순서로 제공한다. 항목 선택 시 기존 작성 탭을 열며, 계층 행별 추가는 이번 범위에 포함하지 않는다. 메뉴는 키보드 이동·Esc·바깥 클릭 닫기와 화면 경계 보정을 지원한다.

## 구조와 식별자

- 기본 구조는 에픽 → 마일스톤 → 이슈이며 에픽 → 이슈 직속도 허용한다. 직속 이슈는 가상 미지정 그룹 없이 에픽 바로 아래 표시한다. 에픽·마일스톤 모두 미지정인 이슈도 지원한다.
- 한글 표시는 이슈, 영문 표시는 Issue다. 기존 `TASK` ID·`tasks` 폴더·`task` CLI 명령·JSON 키는 호환을 위해 유지한다.
- 에픽은 `EP001`, 마일스톤은 `MS001`, 작업은 프로젝트 접두어의 독립 일련번호로 생성한다. 표시용 하이픈 설정을 동일하게 적용한다.
- 소속 이동·제목 변경은 ID·파일명·댓글·선행 참조를 변경하지 않는다. 에픽/마일스톤 코드를 결합한 작업 ID와 이동 시 번호 변경은 채택하지 않는다. 외부 문서·커밋·댓글·세션의 참조를 유지하기 위해서다.
- 삭제한 번호는 재사용하지 않는다. 기존 작업 접두어가 EP인 프로젝트도 읽을 수 있고, 생성 시 이미 사용 중인 ID를 건너뛴다.

## 저장과 기존 문서

- `worktree.json`의 데이터 위치는 유지한다. 에픽은 데이터 폴더의 `epics/EP001.md`에 제목·선택 목표 기간·생성/수정 시각을 저장한다.
- 마일스톤의 선택 `epic`은 원본 에픽 ID 또는 `-`다. 생략하면 에픽 미지정이다. `project.json`의 선택 `nextEpicNumber`는 생략 시 1부터 유효한 다음 번호를 계산한다.
- 이슈는 `milestone` 소속 또는 선택 `epic` 직속 소속 중 하나만 지정한다. 나머지는 `-` 또는 생략이다. 두 소속을 동시에 지정한 문서는 거부한다. 마일스톤을 통한 에픽은 소속 마일스톤에서 계산하며 중복 저장하지 않는다.
- schemaVersion은 1을 유지한다. 에픽 폴더·소속 정보가 없는 기존 문서는 변경 없이 읽으며, 읽기만으로 파일을 저장하거나 기본 에픽을 생성하지 않는다.
- 화면의 에픽 미지정 묶음은 가상 그룹이며 저장하지 않는다. 에픽 생성·배정은 사용자의 명시적 저장으로 적용한다.
- 새로운 앱/CLI가 이전 문서를 읽는 호환이다. 에픽 데이터를 저장한 문서를 이전 앱·CLI에서 사용하는 것은 지원하지 않는다. 앱 0.34.0 / CLI 0.6.0 이상을 함께 사용한다.

## 집계와 삭제

- 일반 이슈만 이슈 수·완료 수·개수 진행률에 포함한다. 에픽 진행률·상태는 직속 이슈와 소속 마일스톤 아래 이슈를 중복 없이 집계한다.
- 에픽은 선행 이슈로 지정할 수 없다. 마일스톤은 에픽만 부모로 지정하며, 이슈는 에픽 또는 마일스톤을 직속 부모로 지정한다.
- 앱의 에픽 삭제는 에픽만 지우고 하위 마일스톤·이슈를 유지한다. 직속 이슈와 마일스톤의 에픽 소속을 해제한다.
- 마일스톤 삭제 시 이슈 유지 옵션은 기존 에픽에 직속으로 이슈를 남긴다. 에픽이 없으면 전체 미지정으로 남긴다.
- CLI의 하위 삭제 정책은 명시적으로 선택한다. 연쇄 삭제 시 자손 작업의 댓글과 외부 선행 참조 동의도 같은 저장 트랜잭션에서 처리한다.
- 에픽 파일도 전체 스냅샷·충돌 검사·OS 잠금·경로/링크·파일 수/내용 제한과 복구 대상이다.

## 검증과 인수

기존 파일의 무변경 읽기, 에픽 CRUD·마일스톤 이동, ID 충돌 회피·번호 비재사용, 작업/공수 중복 없는 집계, 자손 삭제·댓글·참조 처리, 앱 생성/배정/삭제와 CLI 저장을 관련 테스트로 검증한다. 실제 WebView2 배치와 사용자 인수는 자동 검사와 구분한다. TASK028·TASK029는 전체 Node 274개와 타입·포맷·버전·앱/CLI 빌드 검증 후 2026-10-30 사용자의 완료 처리 승인에 따라 done 처리했다. 게시·설치·종합 Windows 인수는 별도 범위다.
