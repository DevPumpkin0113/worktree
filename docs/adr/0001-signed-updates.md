# 0001. 서명을 검증하는 명시적 앱 업데이트

- 결정일: 2026-10-20
- 상태: 채택

Tauri 공식 updater로 GitHub 정식 릴리즈를 설치한다. 최신 릴리즈 API는 구형 배포·개발 버전 구분에 사용하고 서명 manifest와 버전·Windows x64 설치 URL이 일치할 때만 설치를 허용한다. 자동 확인은 앱 시작 시 한 번이며 설치는 사용자 확인 후 진행한다.

기존 NSIS 배포 흐름을 유지하면서 변조된 설치 파일 실행과 개발 앱의 다운그레이드를 막기 위함이다. 서명 없이 exe를 내려받아 실행하는 방법은 제외한다. 비밀 키·암호는 Git 제외 경로와 Actions secrets로 관리하고 공개 키만 앱에 포함한다.

개인 문서를 서버로 전송하지 않는다. 문제 제보는 최소 앱 정보가 채워진 작성 화면만 열며 사용자가 제출한다.
