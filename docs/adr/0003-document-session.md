# 0003. 최근 파일과 열린 문서 세션 저장

- 결정일: 2026-10-20
- 상태: 채택

최근 파일 12개와 마지막 열린 탭 최대 40개, 활성 문서·문서별 보기·간트 단위를 %LOCALAPPDATA%/Worktree/session.json에 저장한다. 문서 내용이나 상세·스크롤은 저장하지 않으며 settings.json의 schemaVersion 1과 이전 방식은 유지한다. 세션 경로는 로컬 사용자 데이터이고 외부 전송하지 않는다.

Rust에서 경로·형식·개수·중복과 파일 크기를 검사하고 같은 디렉터리의 임시 파일을 동기화한 후 교체한다. 손상·미지원 세션은 보존하고 저장을 막아 오류를 안내한다. 복구하려면 앱 종료 후 session.json을 다른 곳으로 옮겨 보존하고 다시 실행한다. 누락·권한 오류가 있는 문서만 건너뛰고 최근 목록은 남겨 재시도할 수 있게 한다. 실행 인자·드롭 요청은 이전 세션 복원 후 처리한다.

localStorage 저장은 기존 JSON 설정 결정과 일관되지 않아 제외했다. 설정 파일에 문서 경로를 섞는 방안은 설정 규격과 이전 절차에 영향을 주므로 제외했다. 전체 원문 캐시와 무제한 탭 저장은 개인정보·용량·시작 지연을 줄이기 위해 제외했다. 열린 탭이 40개를 넘으면 마지막 40개를 저장하며 활성 탭을 포함한다. 원본 문서 자동 수정·삭제는 수행하지 않는다.
