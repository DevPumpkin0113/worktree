# 문서별 공수 표시

- 결정: WBS 메타데이터 use_effort의 true/false로 공수 사용 여부를 지정한다. 생략은 true이며 앱 전체 설정에 저장하지 않는다.
- 이유: 공수를 사용하는 프로젝트와 사용하지 않는 프로젝트를 같은 앱에서 열 수 있고 기존 문서의 표시를 유지해야 한다.
- 영향: false는 공수 관련 화면만 숨긴다. 원본 공수와 검증·계산 규칙 및 schema_version 1을 유지한다. 이전 앱은 항목을 무시하므로 표시 제어는 0.13.0 이상에서 지원한다.
- 제외한 대안: 앱 전체 설정은 문서마다 다른 선택을 담지 못한다. 공수 열 제거는 기존 파서와 문서 호환성을 깨뜨린다. 생략 시 false는 기존 문서의 표시를 바꾼다.
