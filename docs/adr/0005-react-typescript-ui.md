# React·TypeScript 프런트엔드

- 결정: 0.15.0부터 Vite 위에 React·TypeScript를 사용한다. Tauri·Rust와 npm은 유지한다.
- 이유: 워크스페이스·여러 보기·상세·댓글·설정의 상태가 늘어 DOM 직접 갱신과 수동 복원 연결의 유지보수 비용이 커졌다. 컴포넌트와 타입, DOM과 독립된 상태 저장소로 책임을 나눈다.
- 유지: WBS 규격·파서·집계·JSON 설정·세션 계약과 기존 UI 동작. 계산 검증된 간트·네트워크 SVG는 ChartView 내부 어댑터에서 재사용한다.
- 제외: Bun 실행·빌드 체계 전환은 이번 문제를 해결하는 데 필요하지 않다. 전체 바닐라 UI 유지 대신 React로 상태와 화면을 연결한다. Next.js·서버·전역 상태 라이브러리는 현재 로컬 Tauri 흐름에 필수가 아니므로 추가하지 않는다.
- 대체: AGENTS의 src/main.mjs 중심 DOM 연결 안내를 src/main.tsx·컴포넌트·WorkspaceStore 구조로 대체한다. 댓글 저장·작성자 정책은 이 결정으로 확정하지 않는다.

- 범위 확정: 사용자 요청에 따라 재사용하는 도메인·SVG·저장·입력 모듈도 .ts로 전환하고 strict 검사에 포함한다. Node 실행용 개발 스크립트와 기존 단위 테스트의 .mjs는 유지한다.
