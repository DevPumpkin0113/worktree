# 앱 표시 언어 설정

- 결정: 앱 설정의 일반 메뉴에서 ko/en을 선택하고 저장 성공 후 즉시 화면에 적용한다. 기본값은 ko다. 설정 schemaVersion 2에 language를 저장한다. 기존 v1은 메모리에서 v2·ko로 읽고 설정 저장 시 v2로 기록한다. 저장 실패·알 수 없는 미래 버전의 원본 보존 정책은 유지한다.
- 이유: UI와 영어 리소스가 준비되어 사용자가 언어를 선택할 수 있어야 한다. 이전 앱이 새 필드를 손상된 v1 설정으로 오해해 복구하지 않도록 새 스키마 버전을 사용한다. 현재 앱은 알려진 v1과 v2만 읽는다.
- 구조: messages는 현재 언어 리소스를 가리키는 진입점이다. 언어 변경 후 WorkspaceStore 알림으로 화면을 다시 렌더링한다. 모듈의 상태·유형·페이지 이름은 getter로 조회하고 SVG 메모도 언어 변경을 반영한다. 네이티브 메시지는 설정 로드·저장 후 동일 언어를 사용한다.
- 대체 관계: 0006의 언어 선택 보류를 이 결정으로 대체한다. 문서 오류 전체의 번역 보류는 유지한다. 문서 파서와 오류 상세는 ko 리소스를 직접 참조해 한국어 정규식 계약을 보존한다. 따라서 영어 UI에서도 WBS 오류 상세는 한국어다. 오류 코드 없이 검증 문장만 영어로 바꾸는 대안은 위치·수정 안내를 손상시켜 제외한다.
- 범위: 사용자 문서·이름·경로·댓글 내용과 WBS 한글 열/섹션은 번역하지 않는다. 작업 날짜의 Asia/Seoul 기준도 유지한다. 문서 오류의 언어별 표시를 완성하려면 후속 오류 코드 계약이 필요하다.

- 후속: 문서 오류의 한국어 유지 결정은 [0008](0008-document-diagnostics.md)의 구조화된 진단 계약으로 대체한다.
