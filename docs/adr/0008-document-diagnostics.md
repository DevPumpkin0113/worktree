# 문서 검증 진단과 표시 언어 분리

- 결정: parseWbs는 DocumentValidationError에 오류 코드와 작업 ID·참조 ID·관계 종류·기대 접두어를 전달한다. 위치·문제 셀·수정 안내는 코드로 결정하며 한국어/영어 문장을 정규식으로 해석하지 않는다.
- 이유: 번역 문구를 변경해도 오류 위치와 수정 안내가 유지되어야 한다. 선행 작업의 부재와 그룹 참조도 별도 데이터로 구분한다.
- 표시: 오류 상세를 만들 때 한국어/영어 표시 값을 준비하고 현재 언어로 조회한다. 열린 문제 패널·상태 표시줄·복사 내용은 다시 파일을 읽거나 검증하지 않고 전환한다. 원본 ID·입력값·행/열·문서 내용은 보존한다. 일반 Error에는 진단이 없으므로 원문을 표시하고 위치를 추측하지 않는다.
- 대체 관계: 0007의 문서 오류 한국어 유지 및 0006의 문장 판별 계약 보존을 대체한다. WBS 한글 섹션·열 규격은 유지한다.
- 제외한 대안: 언어별 문구 정규식은 번역 변경마다 판별 로직도 수정해야 하므로 제외한다. 알 수 없는 일반 오류에서 작업 ID를 추정하는 방식도 잘못된 위치 안내를 만들 수 있어 제외한다.
