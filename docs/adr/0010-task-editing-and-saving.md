# 작업 편집과 원문 보존 저장

- 후속 결정: [ADR 0011](0011-milestone-containers.md)이 마일스톤 유형·번호 발급·문서 규격 관련 결정을 대체한다. 아래는 당시 결정 기록이다.
- 결정일: 2026-10-21
- 결정: 작업 수정과 추가부터 제공한다. 기존 원본 ID와 유형은 변경하지 않고 새 task/milestone의 ID는 문서 접두어와 모든 기존 ID의 최대 번호 다음으로 발급한다. parent/deps는 원본 ID를 참조한다. 빈 group은 현행 검증상 허용되지 않으므로 생성하지 않는다.
- 이유: parseWbs의 그룹 상태는 집계 결과이므로 모델 전체를 직렬화하면 원래 auto와 문서 설명·서식을 손상시킨다. task-editing.ts에서 변경한 셀만 교체하거나 표 끝에 한 행을 삽입하고 결과를 다시 parseWbs로 검증한다. 다른 행·메타데이터·설명·BOM·혼합 개행은 보존한다.
- 입력: 제목·완료 기준은 필수다. 공수 표시 여부는 use_effort를 따른다. 표 셀은 단일 행이며 파이프는 &#124;로 인코딩한다. 문자 그대로의 &#124; 입력은 구분할 수 없으므로 | 입력을 안내한다. 기존 행 수정 시 바뀌지 않은 셀의 원문은 유지한다.
- 저장: 편집 시작 시 path/text/id 스냅샷을 고정한다. save_document는 기존 파일과 스냅샷 바이트를 비교하고, 같은 폴더의 임시 파일에 쓰기·동기화 후 교체한다. 교체 직전에 다시 비교하고 이 앱의 저장은 Mutex로 직렬화한다. 읽기 전용·쓰기 실패·감지된 외부 변경에서는 덮어쓰지 않고 폼 입력을 유지한다. 충돌은 취소 후 최신 문서를 다시 열어 해결한다.
- 한계: 다른 프로그램을 잠그는 트랜잭션은 아니며 마지막 비교와 교체 사이 외부 쓰기까지 원자적으로 비교·교환하지 않는다. 영구 백업·실행 취소·자동 병합·강제 덮어쓰기는 이번 범위에 포함하지 않는다. WBS 규격과 설정·세션 스키마는 유지한다.
- 제외한 대안: 전체 모델 재직렬화는 원문 손실, 자동 저장은 미검증 입력의 기록, 외부 변경 강제 덮어쓰기는 데이터 손실 때문에 제외한다. 일반 Markdown 편집기·문서 생성·작업 삭제·기존 ID/유형 변경은 별도 설계한다.
