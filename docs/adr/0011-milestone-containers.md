# 마일스톤을 작업 목표 묶음으로 전환

- 후속 결정: [ADR 0012](0012-wbs-v2-only.md)가 v1 자동 변환·중첩 group 호환 결정을 대체한다. 아래는 당시 결정 기록이다.
- 결정일: 2026-10-21
- 대체 관계: ADR 0010의 날짜형 milestone·동일 번호 발급·규격 유지 결정만 대체한다. 원문 보존과 충돌 감지 저장 정책은 유지한다.
- 결정: WBS v2에서 milestone은 제목과 선택 목표 기간으로 작업을 묶는 최상위 컨테이너다. 빈 상태를 허용하고 상태·진행률은 일반 하위 작업에서 집계한다. MS 내부 번호를 별도로 발급하며 화면에서는 숨긴다. 일반 작업 번호는 유지한다.
- 이유: 일정 중심 도구에서 기존 최상위 group과 날짜형 milestone의 역할이 겹쳤다. 승인·출시 등 개별 활동은 task로 통합한다.
- 호환: v1 원본을 검증한 뒤 최상위 group→milestone, 기존 milestone→task로 읽는다. 기존 ID·참조·날짜·상태를 보존하고 0 공수는 미정으로 변환한다. 명시적 저장 시만 v2로 쓴다. 중첩 group과 v1 검증·회귀 테스트는 유지한다. 내부 group 모델은 집계·렌더링 재사용을 위한 표현이다.
- 제외 대안: 기존 ID 일괄 자동 재발급은 외부 참조를 깨뜨리므로 제외한다. 날짜형 milestone을 병행하는 방식은 사용자 혼동 때문에 제외한다. v2를 구버전 앱으로 다시 편집하는 호환은 제공하지 않는다.
