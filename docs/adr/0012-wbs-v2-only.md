# WBS v2만 지원

- 결정일: 2026-10-21
- 대체 관계: ADR 0011의 v1 자동 변환 및 중첩 group 호환 결정을 대체한다.
- 결정: 사용자 지시에 따라 이전 문서 호환을 제거한다. schema_version: 2를 필수로 명시하며 원본 유형은 task와 milestone만 받는다. 마일스톤은 최상위 작업 묶음으로만 사용한다. 규격 누락·v1·group·날짜형 milestone을 오류로 안내하며 자동 변환·저장하지 않는다.
- 이유: 기존 사용자가 없는 단계에서 이중 규칙을 유지할 필요가 없고 현재 규칙의 구현과 검증을 단순하게 유지하려는 제품 결정이다.
- 구현 경계: 내부 group 타입은 v2 마일스톤의 집계·렌더링 표현으로만 유지한다. 기존 날짜형 표시·검증과 변환 모듈·호환 예제를 제거한다. 설정·세션 이전과 파일 확장자 처리 정책은 이번 WBS 규격 변경 범위에 포함하지 않는다.
- 제외 대안: 읽기 전용 v1 지원과 저장 시 변환을 남기는 방식은 이중 규칙이 계속 필요하므로 제외한다. 기존 파일이 필요하면 사용자가 작성 가이드에 맞춰 직접 수정한다.
