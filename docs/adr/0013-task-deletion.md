# 삭제 범위와 참조 처리를 사용자에게 선택하게 한다

- 결정일: 2026-10-21
- 결정: 일반 작업과 마일스톤은 상세에서 삭제 확인창을 연다. 마일스톤 하위 작업은 유지하고 상위를 -로 해제하거나 함께 삭제한다. 삭제 집합을 참조하는 외부 작업은 유지하며 사용자가 동의한 경우만 해당 선행 참조를 해제한다. 기본 선택은 하위 작업 유지이며 참조 해제는 사전 선택하지 않는다. 취소하면 원본을 쓰지 않는다.
- 이유: 관련 작업을 삭제하거나 소속을 변경하는 결과를 사용자가 선택하도록 한 제품 결정이다. 삭제 범위·하위 항목·선행 참조 영향을 확인창에서 표시한다.
- 저장: 기존 내용 비교·임시 파일 교체 저장을 재사용한다. 삭제 행과 변경된 상위/선행 셀만 패치하고 나머지 원문을 보존한다. 실패·충돌 시 선택을 유지한다. 실행 취소·영구 백업·자동 병합은 제공하지 않는다.
- 번호: 삭제한 번호를 재사용하지 않도록 next_task_number·next_milestone_number 양의 정수 메타데이터에 삭제 전 다음 번호를 보존한다. 신규 발급은 현재 최대 번호+1과 보존 번호 중 큰 값을 사용한다. 번호는 일반 작업과 마일스톤별로 관리한다.
- 제외한 대안: 관련 작업 자동 연쇄 삭제와 사용자 동의 없는 참조 해제는 의도치 않은 변경이므로 제외한다. 후속 작업 삭제를 재귀 확장하지 않는다. 이슈·설명 문장 속 ID는 구조화된 작업 참조가 아니므로 임의 변경하지 않는다.

- 삭제 후 표시: 유지된 최상위 작업은 트리 마지막 미지정 묶음으로 보여 준다. 실제 마일스톤이나 문서 행을 생성하지 않으며 접기·펼치기와 전체 미지정 작업의 완료 수 기반 진행률만 제공한다.
