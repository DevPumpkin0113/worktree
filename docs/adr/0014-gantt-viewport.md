# 간트의 고정 배율과 가시 구간 렌더링

- 결정일: 2026-10-21
- 결정: 일 단위는 7일·오늘 중앙, 주 단위는 5주·현재 주 중앙으로 처음 연다. 주는 월요일 시작 ISO 연간 주차로 표시하고 툴팁에 연도·기간을 제공한다. 창 크기에 맞춰 날짜 셀 폭을 계산한다.
- 이유: 전체 일정 길이에 따라 배율을 축소하면 사용자가 요청한 7일·5주 화면을 유지할 수 없다. 전체 날짜 범위와 가시 구간을 분리해 축과 막대는 보이는 부분만 렌더링한다.
- 긴 범위: 실제 스크롤 트랙은 18,000px 이내로 두고 전체 날짜 범위에 선형 매핑한다. SVG 크기는 뷰포트 크기로 유지해 매우 긴 기간의 대형 DOM·SVG를 피한다. 긴 범위에서는 트랙 이동에 대응하는 날짜 간격이 커질 수 있지만 표시 배율은 일정하다.
- 상태: 문서와 일/주 단위별로 날짜 앵커 및 스크롤을 현재 창 메모리에 보존한다. 새 문서 최초 진입만 기본 중앙 위치를 쓰며 사용자의 탐색을 필터·갱신·리사이즈로 초기화하지 않는다. WBS 내용·세션 규격은 변경하지 않는다.
- 구조: 간트는 React SVG, 순수 날짜 계산과 뷰포트 훅을 분리한다. 기존 네트워크는 문자열 SVG 어댑터를 유지한다. 포인터 이동은 공용 훅으로 재사용하며 간트·네트워크 스크롤 프레임에 좌우·하단 10px 여백을 둔다.
- 제외한 대안: 전체 기간을 고정 SVG 폭에 압축하는 방식은 배율 요구에 어긋난다. 모든 날짜를 SVG에 생성하는 방식은 긴 범위에서 브라우저 크기·성능 제한을 만든다. 월별 주차 대신 ISO 주차를 사용해 월·연도 경계에서도 연속된 7일 단위를 유지한다.
