# 0016 프로젝트별 ID 표시 규칙

- 상태: 확정
- 날짜: 2026-10-21

## 결정

ID 하이픈 표시 설정의 소유권을 앱에서 프로젝트로 옮긴다. project.json에 선택 idSeparator(none/hyphen)를 추가하며 생략은 none이다. 초기화와 프로젝트 관리에서 지정한다. 저장 schemaVersion은 1을 유지한다. 0002의 앱 ID 구분자 설정 결정만 이 기록으로 대체하고 나머지 앱 설정 저장 방식은 유지한다.

## 이유

프로젝트별 번호 표기를 독립적으로 관리하고 같은 문서 집합을 여는 사용자에게 동일한 표시를 제공한다. 원본 ID·경로·관계에는 영향을 주지 않는다.

## 제외한 대안

- 앱 설정과 프로젝트 설정을 함께 적용: 우선순위가 모호하고 같은 문서 표시가 사용자마다 달라진다.
- 기존 전역 값을 모든 프로젝트에 자동 복사: 요청하지 않은 프로젝트 파일 변경과 표시 규칙 전파를 만든다.
- 원본 ID에 하이픈 삽입: 파일명과 선행 참조 변경을 요구한다.

## 영향

앱 UI와 실행 상태의 전역 구분자를 제거한다. settings.json의 기존 속성은 설정 파일 형식 호환만을 위해 유지하고 표시에서 무시한다. 기존 프로젝트는 하이픈 없음으로 읽고 원하는 경우 프로젝트 관리에서 저장한다. 날짜 포맷과 초기화 작업 규칙 단계 확대는 검토 후보이며 이번 결정에 포함하지 않는다.
