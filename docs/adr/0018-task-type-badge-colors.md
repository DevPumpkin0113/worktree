# 0018 작업 유형·공통 라벨 뱃지와 유형 색상

- 상태: 확정
- 날짜: 2026-10-22

## 결정

초기화·프로젝트 관리에서 작업 유형과 공통 라벨을 공용 BadgeInput으로 추가·삭제한다. 기존 taskTypes/labels 문자열 배열은 유지하고 선택 taskTypeColors 맵에 유형별 6자리 HEX 색상을 저장한다. 색상을 지정하지 않으면 기본 7종은 기본 팔레트, 사용자 유형은 중립 배경이다. 초기화와 프로젝트 설정 저장에서 검증하며 작업 보드·목록·상세에서 같은 색상으로 표시한다. 저장 schemaVersion 1은 유지한다.

## 이유

쉼표 목록보다 개별 유형·라벨의 추가·삭제와 색상 선택을 직접 확인하기 쉽다. 색상은 프로젝트의 유형에 속하며 같은 문서 집합을 여는 사용자에게 공유된다. ID·작업 파일·관계는 변경하지 않는다.

## 제외한 대안

- 유형 배열을 객체 배열로 교체: 기존 유형 문자열·검증·작업 참조 구조를 바꾸는 비용이 불필요하다.
- 작업마다 유형 색상을 복제: 같은 유형 색상이 작업별로 달라지고 일괄 변경이 어렵다.
- 앱 설정에 색상 저장: 프로젝트 규칙을 공유할 수 없다.

## 영향

사용 중인 유형은 UI와 저장 경계에서 제거를 막는다. 제거된 미사용 유형의 색상은 함께 정리한다. 공통 라벨 목록을 제거해도 작업에 저장된 라벨은 유지한다. 공용 뱃지의 기본 배경·테두리는 테마 변수를 사용하고 사용자 지정 색상은 검증된 CSS 변수 값으로 전달한다.


## 2026-10-22 기본 구성 및 표현 확정

기본 유형은 feature·bug·improvement·task·docs·spike·chore이며 원문으로 표시한다. 참고 팔레트(https://velog.io/@rimo09/Github-github-label-%ED%95%9C%EB%B2%88%EC%97%90-%EC%A0%81%EC%9A%A9%ED%95%98%EA%B8%B0)를 바탕으로 유형별 기본색을 지정한다. 기존 모서리 형태와 옅은 유형색 배경을 유지한다. 옅은 배경과 진한 유형색 글자를 사용하며 흰색/검은색 자동 선택은 하지 않는다. 라벨은 색상 선택 없이 중립 배경과 예시 텍스트만 제공한다. 예시를 기본값으로 저장하지 않는다.
