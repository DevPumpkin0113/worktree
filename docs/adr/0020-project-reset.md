# 0020. 프로젝트 문서 집합 재초기화

- 상태: 대체됨 (2026-10-22, ADR 0021)
- 연결: 0015의 문서 집합 저장 구조 유지. 초기화 버튼의 UI 미리보기 제한을 대체.

이 문서는 초기 파일별 삭제 결정의 기록이다. 사용자가 데이터 저장 폴더 전체 삭제를 선택하여 [0021](0021-reset-data-directory.md)로 대체했다.

## 결정

프로젝트 관리에서 정확한 프로젝트명 입력 확인 후 Worktree 관리 문서를 삭제하고 생성 단계로 돌아간다. 루트 worktree.json, 데이터 위치의 project.json 및 스냅샷에 포함된 작업·마일스톤 문서만 삭제한다. 다른 작업물·파일은 보존하고 폴더는 비어 있을 때만 제거한다. 새로운 문서 집합의 번호는 1부터 시작한다.

삭제는 전체 스냅샷 및 파일별 비교와 루트 .worktree-reset.json 복구 기록을 사용한다. pending은 중단 복구 시 이전 문서를 복원하되 외부 변경을 덮어쓰지 않는다. 완료는 문서 본문 없이 데이터 경로만 기록하는 cleared 영수증으로 교체한다. 영수증이 일치할 때만 남은 일반 파일을 보존하며 같은 데이터 위치를 재사용한다. 생성 완료 시 정리한다. Git에서 제외하며 영구 백업·사용자 실행 취소는 제공하지 않는다.

## 이유

일정 관리를 처음부터 다시 시작하면서 프로젝트 소스와 참조 자료는 보존한다. 삭제 중 장애의 복구 가능성을 유지하고, 완료된 삭제 문서를 앱 설정·세션·영구 복사본에 남기지 않는다. 재생성은 사용자에게 새 이름·저장 위치·규칙을 선택하도록 한다.

## 제외한 대안

- 데이터 폴더 재귀 삭제: 함께 둔 일반 파일까지 삭제할 수 있다.
- 삭제 즉시 기존 규칙으로 자동 생성: 새 초기화 단계에서 규칙을 다시 선택할 수 없다.
- 영구 백업: 현재 실행 취소·백업 정책의 범위 밖이다.
