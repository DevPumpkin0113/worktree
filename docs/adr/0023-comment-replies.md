# 0023. 댓글 번호와 한 단계 답글

- 상태: 확정 (2026-10-22, 박대호 결정)
- 연결: 0022 댓글별 문서 구조 유지. 댓글 삭제의 파일 제거 방식을 삭제 표식으로 구체화.

## 결정

작업별 고정 number를 #001 형태로 표시한다. 답글은 rootId와 replyTo를 저장하여 화면은 원댓글 아래 한 단계로 유지하고 직접 답한 대상은 본문 앞의 강조 번호로 표시한다. 삭제 시 본문을 비우고 deleted 표식을 남기며 답글은 유지한다. 참조되는 삭제 댓글만 자리 표시를 남긴다. UUID 파일명은 유지하고 별도 공용 카운터는 추가하지 않는다.

댓글의 생성 시각만 화면에 표시하며 수정 시각 저장은 유지한다. 답글이 달린 댓글의 수정은 비활성화하고 저장에서도 거부한다. 삭제 표식으로 남은 답글도 포함하여 이미 이어진 대화의 맥락을 보존한다.

## 이유

중첩이 깊어지는 것을 막으면서 대화 대상을 명확히 한다. 삭제 후 번호 재사용과 연결 끊김을 방지하고 작업 파일 편집과 댓글 저장을 분리한다. 기존 번호 없는 댓글은 읽기만으로 수정하지 않고 다음 명시적 저장에서 번호를 고정한다.

## 제외한 대안

- 원댓글과 답글 동시 삭제: 사용자가 답글 보존을 선택했다.
- 무제한 중첩: 한 단계 답글 요구와 맞지 않는다.
- UUID를 화면 번호로 표시: 대화에서 짧게 참조하기 어렵다.
- 프로젝트 공용 카운터: 댓글마다 공용 파일을 변경하게 된다. Git 병합에서 작업별 번호가 충돌하면 명시적 오류로 안내한다.
