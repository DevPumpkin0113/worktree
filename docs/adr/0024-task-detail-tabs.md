# 0024. 모달 상세를 콘텐츠 탭 보기로 교체

- 상태: 확정 (2026-10-22, 박대호 결정)
- 연결: 기존 우측 패널·댓글 저장 방식은 유지. 작업 상세 모달의 표시 정책을 대체.

## 결정

제목·설명·진행률 헤더 아래에서 콘텐츠를 홈 또는 작업별 상세 탭으로 전환한다. 홈은 SVG 집 아이콘으로 표시한다. 작업별 탭은 중복되지 않으며 닫기와 키보드 전환을 지원한다. 홈을 마운트 상태로 유지하고 스크롤·접힘을 복원한다. 상세 렌더러와 댓글 초안은 우측 패널과 공유한다.

열린 탭과 활성 탭은 프로젝트별 현재 창 메모리에만 둔다. 프로젝트 닫기·초기화·앱 종료로 해제하고 작업 삭제 시 해당 탭을 정리한다. 앱 설정 detailMode는 sidebar/tabs이며 이전 modal은 읽기에서 tabs로 변환하고 다음 저장에 반영한다. 기본 sidebar·설정 schemaVersion 2·프로젝트·세션 파일 규격은 유지한다.

## 이유

넓은 상세 화면과 여러 작업을 오가는 흐름을 제공하면서 홈의 목록 상태를 보존한다. 우측 분할의 목록 비교 장점은 유지하되 모달을 별도 표시 방식으로 관리하는 비용은 줄인다. 하단 프로젝트 탭과 상단 작업 탭의 역할을 구분한다.

## 제외한 대안

- 분할 보기만 유지: 상세 설명·댓글이 넓은 공간을 필요로 할 때 메인 목록 너비가 줄어든다.
- 모달을 추가로 유지: 세 종류의 상세 보기 동작과 포커스를 관리해야 한다.
- 탭 전환마다 홈을 재생성: 스크롤·접힘과 편집 상태가 불필요하게 초기화된다.
- 열린 작업 탭을 디스크 세션에 저장: 이번 범위는 현재 창의 탐색으로 한정한다.

작업 탭의 메모리 한정 정책은 후속 ADR 0025에서 세션 저장·재시작 복원으로 대체했다.
