# 0025. 작업 탭의 세션 저장·복원

- 상태: 확정 (2026-10-22, 박대호 결정)
- 대체: 0024의 작업 탭을 현재 창 메모리에 한정한 정책. 탭 구조와 기본 분할 보기 정책은 유지.

## 결정

작업 탭의 원본 ID 순서와 마지막 활성 ID를 프로젝트별 session.json에 저장하고 앱 재시작 시 복원한다. schemaVersion 2의 문서별 tabs 항목에 선택 taskTabs 배열과 activeTaskTab을 추가한다. 생략 값은 빈 탭·홈으로 읽으며 실제 프로젝트에서 삭제된 ID는 제외한다. 홈 선택은 null로 저장하고 프로젝트 닫기·초기화는 기존 캐시와 세션에서 해당 탭을 해제한다. 작업·댓글 내용 및 댓글 초안은 저장하지 않는다.

설정 로드와 세션 복원의 순서가 달라도 활성 탭을 복원한다. 기존 세션 원자 저장·큐·실패 보존을 유지하고 중복/잘못된 ID·배열 밖 활성 ID를 거부한다. 세션의 128KiB 한도와 문서별 2,000개 작업 탭 한도를 적용한다. 0.30.0 이전 앱은 새 세션 필드를 지원하지 않는다.

## 이유

작업 중 앱을 종료해도 여러 작업을 다시 찾아 여는 부담을 줄인다. 경로와 ID만 저장해 프로젝트 내용의 별도 사본을 만들지 않는다.

## 제외한 대안

- 메모리 한정: 재시작 후 열린 작업을 잃는다는 사용자 피드백으로 변경했다.
- 작업 파일 또는 project.json에 탭 저장: 개인 탐색 상태가 팀 공유 데이터와 섞인다.
- 댓글 초안까지 저장: 내용 복사본을 앱 세션에 남기므로 이번 범위에서 제외한다.
