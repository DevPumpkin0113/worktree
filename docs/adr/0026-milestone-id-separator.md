# 0026. 마일스톤 원본 ID에 프로젝트 구분자 적용

- 상태: 철회 (2026-10-22, 후속 사용자 결정으로 0027이 대체)
- 변경: MS 접두어·별도 번호 체계는 유지하며 구분자를 표시용으로만 취급하던 마일스톤 생성 정책을 변경.

## 결정

새 마일스톤의 원본 ID와 파일명은 프로젝트 idSeparator가 hyphen이면 MS-001, none이면 MS001로 생성한다. 별도 nextMilestoneNumber와 삭제 번호 재사용 금지를 유지한다. 기존 ID는 재작성하지 않고 두 형태 모두 읽는다. 작업 소속·댓글 폴더·열린 탭의 세션에는 원본 ID를 정확히 기록한다. 일반 작업의 원본 ID 생성 규칙은 이번 범위에서 변경하지 않는다. 마일스톤 접두어 사용자 지정은 후속 개선 후보로 남긴다.

## 이유

사용자가 초기화의 ID 형식에서 고른 구분자를 마일스톤의 원본 ID에도 적용하기를 요청했다. 기존 참조를 일괄 변경하지 않고 이후 생성부터 반영하여 저장 충돌·대화 연결을 보존한다.

## 제외한 대안

- 화면에서만 하이픈 표시: 사용자가 원본 ID와 파일명에도 적용하도록 명시했다.
- MS 대신 일반 작업 접두어·공용 번호 사용: 사용자가 MS 접두어 유지를 선택했다.
- 기존 마일스톤 일괄 재번호·이름 변경: 이번 범위에 포함하지 않는다.

구현 검토 후 작업/마일스톤 구분자를 모두 표시용으로 통일하기로 결정하여 원본 하이픈 생성·파일/댓글/세션 지원 변경을 미커밋 상태에서 되돌렸다. 현행 정책은 ADR 0027이다.
