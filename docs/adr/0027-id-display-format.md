# 0027. ID 구분자를 표시 형식으로 통일

- 상태: 확정 (2026-10-22, 박대호 결정)
- 대체: 0026의 마일스톤 원본 구분자 적용 결정을 철회. 원래 원본 ID 불변 정책을 작업·마일스톤 모두에 적용.

## 결정

작업 W002와 마일스톤 MS002는 생성부터 원본 ID·파일명을 하이픈 없이 유지한다. idSeparator는 화면 표시만 W-002·MS-002로 바꾼다. 프로젝트 설정·초기화 명칭을 ID 표시 형식으로 변경한다. 소속·댓글 폴더·세션·연결은 원본 문자열을 유지하며 구분자 변경으로 파일을 다시 쓰지 않는다. 마일스톤은 MS 접두어와 별도 번호 순서를 유지하고 접두어 설정은 후속 개선으로 남긴다.

## 이유

구분자를 바꾸어도 기존 ID와 연결이 일관되게 유지된다. 원본 ID와 표시 ID의 역할을 분명히 하도록 설정 명칭을 바꾼다.

## 제외한 대안

- 마일스톤에만 원본 하이픈 적용: 일반 작업과 규칙이 달라져 혼동한다.
- 작업도 원본 하이픈 적용: 설정 변경과 저장 식별자를 결합하고 참조·파일 이름 관리 비용을 늘린다.
