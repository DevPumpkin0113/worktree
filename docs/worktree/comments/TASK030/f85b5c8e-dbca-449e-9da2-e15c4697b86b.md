정렬 요구 정정: 중앙 정렬이 아니라 사이드바 오른쪽부터 시작하는 콘텐츠 영역의 왼쪽에 새로고침·검색을 정렬한다. 타이틀바 시작 위치는 사이드바 너비만큼 유지하고 내부 패딩을 콘텐츠와 같은 --workspace-content-padding으로 맞췄다. 중단 도중 적용된 가운데 정렬은 해제했다. CSS 포맷 검사 통과, 사용자 실제 화면 확인 대기.
