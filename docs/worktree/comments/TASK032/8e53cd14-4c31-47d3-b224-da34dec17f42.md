필터 참고 화면을 반영해 상태·우선순위·이슈 유형·담당자를 아이콘과 화살표가 있는 항목 목록으로 구성했다. 항목 클릭 또는 오른쪽 화살표로 값 선택 목록을 옆에 열고 왼쪽 화살표로 닫는다. 선택 값은 항목 오른쪽에 표시한다. 공간에 따라 좌우 배치를 전환하고 좁은 창은 기본 위아래 배치를 사용한다. 공용 드롭다운의 기존 기본 동작은 유지했다. 타입·포맷·Vite 빌드 및 관련 테스트 84개 통과. 실제 WebView 배치 사용자 확인 대기.
