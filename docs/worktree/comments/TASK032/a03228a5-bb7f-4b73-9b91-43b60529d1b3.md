탭 높이를 실제로 강제하던 기존 ID 선택자 #workspaceTools의 min-height:42px와 align-items:center를 확인해 제거했다. 같은 ID 아래 필터 버튼의 min-height:42px 재정의도 제거해 패널의 34px 항목 규칙이 적용되도록 했다. 이전 22px 설명은 해당 상위 최소 높이를 놓쳐 부정확했음을 정정한다. 이제 탭 행은 내부 요소 기준으로 결정되며 도구 버튼도 행 높이에 늘어난다. CSS 포맷·Vite 빌드·diff 검사 통과. 실제 렌더링 높이 사용자 확인 대기.
