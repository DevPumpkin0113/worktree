Tree 1차 UI 개선: 전용 tree-view 스타일로 다른 보기와 분리했다. 중첩 박스 테두리는 들여쓰기와 가이드 선으로 바꾸고 그룹 헤더를 한 줄 중심으로 줄였다. 진행률은 오른쪽으로 모으고 목표 기간 미정 문구는 생략한다. 이슈는 ID·세로 우선순위 표시·제목·유형·담당자·상태를 36px 최소 행 높이에 배치하며 긴 제목은 툴팁과 말줄임으로 처리한다. 좁은 콘텐츠에서는 보조 정보를 다음 줄로 배치한다. 네이티브 details 접기·펼치기와 상세 버튼, 선택·키보드 포커스를 유지했다. strict 타입·전체 포맷·React 통합 80개·시각화 관련 14개·Vite 빌드·작업판 검증 통과. 실제 WebView 배치와 사용성은 사용자 확인 대기이며 소스는 미커밋으로 유지한다.
