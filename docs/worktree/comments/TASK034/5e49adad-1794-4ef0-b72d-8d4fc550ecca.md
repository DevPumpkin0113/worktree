최종 방향은 Unicode 이모지를 유지하면서 Lucide 아이콘을 추가하는 것으로 확정했다. 에픽 생성·편집 제목 왼쪽에 선택 버튼을 두고, 기존 에픽 제목 아이콘 클릭은 편집과 선택창을 바로 연다. 아래에 뜨는 Icons/Emojis 선택창에서 검색·선택하며, Esc·외부 클릭은 선택창만 닫고 파일 변경은 저장·취소로 확정한다. Lucide는 패키지의 지원 카탈로그만 정적 매핑하고 lucide:name으로 저장하며, 표준 이모지와 legacy6은 보존한다. 기본 마일스톤 마름모 SVG는 유지한다. 선택기 데이터는 앱에 포함하고 이모지 모듈만 필요 시 불러온다. 메인이 중단된 개발 서브의 실제 core/CLI 변경을 확인하고 UI와 통합했다. 전체 검사에서 번역 리소스의 문자열 계약과 core의 무의존성 가정을 발견해 번역은 평면 문자열로 정리하고 core는 고정 버전의 순수 emoji-regex만 허용하도록 명시했다. React·Tauri·desktop 의존 금지는 유지하며 결정은 docs/EPICS.md에 기록했다. 최종 strict 타입·전체 포맷·제품 버전 검사·CLI/helper 빌드·Vite 빌드·전체 테스트 287개·작업판 검증 통과. Vite는 앱/이모지 chunk 500kB 경고가 있으며 이모지는 지연 로딩한다. 실제 WebView 배치와 OS 이모지·네이티브 키보드 인수는 사용자 확인 대기, 소스 미커밋.
