별도 기능 작업으로 구현했다. 마일스톤은 고정 윤곽선 마름모 SVG이며 에픽은 기본(layers)·폴더·데스크톱·터미널·도구·로켓 중 선택한다. 생성·편집에 네이티브 라디오 선택기를 추가하고 명시 저장·취소 및 실패 시 초안 보존을 유지했다. Tree의 종류 텍스트 배지를 아이콘으로 바꾸고 상세 제목에도 표시한다. core의 선택 icon 필드는 비기본값만 저장하며 layers·CLI -는 필드 생략으로 정규화한다. 기존 에픽은 읽기만으로 변경하지 않고 기본 아이콘으로 표시한다. CLI add/edit·JSON·show/list·schema/help도 같은 카탈로그를 사용한다. 내장 선택값 제한은 임의 SVG·이미지 입력 검증과 파일 관리를 늘리지 않기 위해 채택했고 설계는 docs/EPICS.md에 반영했다. 개발 서브 core/CLI 보고를 메인이 실제 코드와 테스트로 확인했다. 최종 타입·전체 포맷·버전 일치·CLI 빌드·Vite 빌드·전체 테스트 282개·작업판 검증 통과. 실제 WebView 아이콘 배치·네이티브 키보드 조작과 사용자 인수는 대기하며 TASK033과 분리해 doing·미커밋으로 유지한다.
