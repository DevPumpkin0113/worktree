참고 이미지에 맞춰 선택창을 재구성했다. Icons는 밑줄 탭·색상 원형 팔레트·검색·카테고리별 12열 Lucide 목록이며 Emojis는 별도 입력칸과 카테고리 이동바 없이 검색·자주 사용한 항목·카테고리 목록만 표시한다. 기본/프리셋/사용자 지정 HEX 색상은 초안에 유지하고 Lucide에만 적용한다. 선택 iconColor 메타데이터와 CLI --icon-color·JSON·schema를 추가했으며 기존 문서·부분 편집은 보존하고 -는 색상만 초기화한다. 색상 선택은 패널 유지, 아이콘/이모지 선택은 패널 닫기, 저장/취소는 명시적 동작을 유지한다. 전체 Node 테스트 289개·타입·포맷·버전·앱/CLI 빌드 통과. 마지막 키보드 탭 진입 순서 보완 후 React UI 82개를 다시 검증했다. Vite 주 앱 chunk 500kB 경고는 남아 있으며 이모지는 지연 로딩한다. 실제 WebView 배치와 OS 사용자 지정 색상창은 미검증으로 사용자 확인 대기, doing 및 미커밋 유지.
