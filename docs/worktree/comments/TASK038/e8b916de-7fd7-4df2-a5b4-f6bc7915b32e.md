사용자 요청으로 노드·배치는 유지하고 연결선과 화살표만 변경했다. 같은 높이는 직선, 다른 높이는 모서리를 둥글게 처리한 직각 연결로 바꿨다. 노드 양끝에 5px 간격을 두고 6px 코너 반경을 적용한다. 화살표는 채운 삼각형 대신 고정 8px 열린 꺾쇠이며 markerUnits=userSpaceOnUse로 강조 시 크기가 커지지 않는다. 기본/강조 화살표의 선색·두께를 해당 연결선과 일치시키고 끝·모서리를 round 처리했다. 타입·네트워크 도메인 4개·Vite 빌드 통과. 실제 연결선 시각 확인과 사용자 승인 대기로 doing 유지.
