사용자가 기존 완료 작업의 완료일을 예정 종료일과 같게 지정해 현재 프로젝트의 완료 이슈 45개를 CLI batch로 보정했다. 시간이 없는 날짜는 한국 시간 00:00을 적용했으며 실제 시각으로 추정한 값이 아닌 사용자 지정 기준이다. 예정일/상태/제목/계층 등은 유지하고 완료 시각만 채웠으며 완료일 없는 종료일 미지정 항목은 0개였다. 이를 위해 task edit --completed-at 명시 보정을 추가했고 회고 등록 작업은 완료일이 문서 생성일보다 앞설 수 있도록 허용했다. 완료 상태 및 UTC 정규 형식·수정 시각 상한 검증은 유지한다. 보정 전 dry-run, 타입 검사·도메인 3개·실제 CLI 테스트·전체 프로젝트 validate 통과. TASK048의 날짜별 완료 그래프에 기존 데이터도 반영된다.
