## 목적
로컬 프로젝트 운영을 사용할 수 있도록 프로젝트 폴더 열기와 전환 기능/산출물을 제공한다.

## 범위
프로젝트 폴더 또는 worktree.json을 열고 프로젝트 탭으로 전환한다. 최근 목록과 폴더 드롭을 지원한다.

## 완료 조건
여러 프로젝트 전환 시 대상 프로젝트의 마지막 화면을 복원하고 닫은 프로젝트는 최근 목록에 남는다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
