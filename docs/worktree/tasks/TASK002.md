## 목적
로컬 프로젝트 운영을 사용할 수 있도록 프로젝트 초기화와 작업 규칙 설정 기능/산출물을 제공한다.

## 범위
기본 정보·작업 규칙·최종 확인의 3단계로 프로젝트를 생성한다. 저장 위치·접두어·표시 형식·유형·담당자·우선순위·공수 사용을 검증한다.

## 완료 조건
유효한 입력만 문서 집합을 생성하고 기존 데이터를 덮어쓰지 않는다. 실패 단계와 대상 경로를 안내한다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
