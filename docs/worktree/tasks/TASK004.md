## 목적
로컬 프로젝트 운영을 사용할 수 있도록 프로젝트 데이터 재초기화 기능/산출물을 제공한다.

## 범위
정확한 프로젝트명 확인 후 데이터 폴더 전체와 루트 마커를 삭제하고 생성 화면으로 돌아간다.

## 완료 조건
상위 폴더·저장 위치 밖 파일을 유지하며 링크·읽기 전용·복구 단계 검사와 실패 안내를 제공한다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
