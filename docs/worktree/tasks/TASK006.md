## 목적
작업 계획과 시각화을 사용할 수 있도록 작업과 마일스톤 문서 모델 기능/산출물을 제공한다.

## 범위
프로젝트별 JSON·작업/마일스톤 Markdown 집합과 원본 ID 규칙을 구현한다. 마일스톤 소속과 가상 미지정 묶음을 구분한다.

## 완료 조건
ID·소속·선행 참조와 집합 일관성을 검사하고 미지정 묶음을 저장 마일스톤으로 계산하지 않는다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
