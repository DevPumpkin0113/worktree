## 목적
작업 계획과 시각화을 사용할 수 있도록 작업과 마일스톤 생성 수정 삭제 기능/산출물을 제공한다.

## 범위
작성 콘텐츠 탭과 상세 내부 편집으로 메타데이터·설명·참조 값을 관리한다. 삭제의 하위 유지/삭제·선행 참조 해제를 확인한다.

## 완료 조건
저장 시 ID를 발급하고 필드 오류를 인라인 표시한다. 실패·충돌 시 초안을 보존한다. 참조는 값 저장·표시 범위다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
