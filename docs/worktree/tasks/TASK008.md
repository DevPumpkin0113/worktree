## 목적

## 범위
마일스톤 트리·상태 칸반·선행 관계 네트워크·작업 목록으로 동일한 프로젝트 작업을 탐색한다.

## 완료 조건

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
