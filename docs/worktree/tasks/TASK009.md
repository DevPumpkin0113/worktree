## 목적
작업 계획과 시각화을 사용할 수 있도록 일 주 단위 간트 일정 탐색 기능/산출물을 제공한다.

## 범위
일 단위 7일·주 단위 5주와 ISO 주차를 표시하고 가시 구간 렌더링·스크롤 위치 유지를 구현한다.

## 완료 조건
오늘/현재 주를 중심으로 탐색하고 프로젝트·단위별 보기 위치를 유지한다. 막대 드래그 일정 편집은 포함하지 않는다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
