## 목적
작업 계획과 시각화을 사용할 수 있도록 작업 검색 필터와 진행률 집계 기능/산출물을 제공한다.

## 범위
검색과 담당자·상태·유형·우선순위 필터, 작업 수·완료 수·진행률과 별도 공수 집계를 제공한다.

## 완료 조건
일반 작업만 개수 진행률에 포함하고 공수 미정 값을 추정하지 않는다. useEffort는 공수 표시만 제어한다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
