## 목적
작업 맥락과 댓글을 사용할 수 있도록 작업 상세 탭과 분할 패널 기능/산출물을 제공한다.

## 범위
공용 상세를 콘텐츠 탭 또는 너비 조절 가능한 우측 패널로 표시한다. 관련 작업 이동과 편집 초안·홈 상태 유지를 지원한다.

## 완료 조건
동일 작업은 기존 탭을 선택하고 외부 삭제 탭을 정리한다. 생성 초안과 단순 탭 이동의 보존 정책을 구분한다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
