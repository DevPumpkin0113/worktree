## 목적
작업 맥락과 댓글을 사용할 수 있도록 댓글 영구 저장과 한 단계 답글 기능/산출물을 제공한다.

## 범위
작업별 댓글 Markdown·고정 번호·직접 답글 대상·삭제 표식과 작성/수정/삭제를 구현한다.

## 완료 조건
답글이 있는 댓글 수정 제한을 저장 경계에서도 검사한다. 실패·충돌 시 초안, 기존 작성자·작성 시각과 답글 번호를 보존한다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
