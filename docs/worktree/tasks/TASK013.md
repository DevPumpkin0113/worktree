## 목적
작업 맥락과 댓글을 사용할 수 있도록 한국어 영어와 프로젝트 표시 형식 기능/산출물을 제공한다.

## 범위
앱 ko/en 표시와 프로젝트별 ID 하이픈·날짜·시간 표시, 유형 배지 색상을 적용한다.

## 완료 조건
표시 변경이 원본 ID·파일명·일정 ISO 날짜·UTC 시각을 바꾸지 않고 언어별 문구를 리소스로 관리한다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
