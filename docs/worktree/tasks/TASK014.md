## 목적
작업 맥락과 댓글을 사용할 수 있도록 외부 갱신 상태 유지와 오류 안내 기능/산출물을 제공한다.

## 범위
외부 변경 읽기와 상세·스크롤·접힘 유지, 상태 표시줄·문제 패널의 파일/필드/원문 위치 안내를 제공한다.

## 완료 조건
삭제 항목 선택을 정리하고 오류 위치를 추측하지 않는다. 정상 복구 시 이전 오류를 해제하며 편집 시작 스냅샷을 유지한다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
