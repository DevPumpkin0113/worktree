## 목적
앱 CLI 공용 개발 기반을 사용할 수 있도록 공용 안전 저장 충돌 검사와 복구 기능/산출물을 제공한다.

## 범위
전체 스냅샷 비교·임시 파일 동기화/교체·복구 기록·프로세스 간 OS 잠금과 경로/링크/용량 제한을 공유한다.

## 완료 조건
외부 수정 충돌을 보존하고 앱/CLI가 같은 Rust 저장 경계를 사용한다. 외부 편집기 전역 CAS·실행 취소·영구 백업은 보장하지 않는다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
