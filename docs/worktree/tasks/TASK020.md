## 목적
터미널 작업 관리을 사용할 수 있도록 CLI 프로젝트 초기화와 설정 편집 기능/산출물을 제공한다.

## 범위
init의 옵션/JSON/대화형 생성과 project show/edit의 설정 조회·부분 변경을 제공한다.

## 완료 조건
질문 취소 전 파일을 생성하지 않고 기존 마커·데이터를 덮어쓰지 않는다. 고정 필드·사용 중 규칙을 보호한다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
