## 목적
터미널 작업 관리을 사용할 수 있도록 CLI 프로젝트 재초기화와 재생성 기능/산출물을 제공한다.

## 범위
project reset의 범위 미리보기·정확한 이름/yes 확인·revision 검사와 삭제 후 init 흐름을 제공한다.

## 완료 조건
링크·읽기 전용을 검사하고 외부 작업물을 유지한다. reset과 init은 별도 단계이며 복원 보장을 제공하지 않는다.

## 검증 방법과 근거
관련 커밋의 구현·검증 기록과 현재 제품 경계를 대조한다. 공용 core/CLI는 관련 Node 테스트·타입 검사를, 저장은 Rust 테스트를, 화면은 관련 통합 테스트와 실제 동작 확인을 사용한다. 이번 등록에서는 전체 테스트나 실제 설치 인수를 새로 실행하지 않았다.
