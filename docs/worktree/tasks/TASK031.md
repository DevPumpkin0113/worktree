목적: Linear 참고 화면처럼 콘텐츠를 독립 패널로 구성한다. 범위: 콘텐츠·상세·문제 패널을 둥근 테두리와 옅은 그림자가 있는 패널로 묶는다. 타이틀바·좌측 탭·하단 프로젝트 탭·상태 표시줄은 패널 밖에 유지한다. 좌측 탭과 콘텐츠 사이 구분선을 제거하고 패널 뒤 배경은 좌측 탭과 같은 색으로 통일한다. 완료 조건: 콘텐츠 내부 스크롤, 고정 헤더, 상세 너비 조절, 설정 inert, 사이드바 접힘을 유지한다. 검증: React 통합·타입·포맷·Vite 빌드. 실제 화면 배치는 사용자 확인이 필요하며 확인 전 doing 유지.
