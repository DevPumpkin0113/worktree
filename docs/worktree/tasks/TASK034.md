목적: 에픽을 Lucide 아이콘 또는 표준 이모지로 구분하고 마일스톤은 고정 마름모 SVG로 표시한다. 범위: 에픽 제목 왼쪽 떠 있는 Icons·Emojis 선택창. Icons는 기본·프리셋·사용자 지정 색상, 검색, 카테고리별 조밀한 목록이며 Emojis는 검색과 자주 사용한 항목·카테고리별 목록이다. 생성·편집 명시적 저장·취소, Tree·상세 제목 표시, CLI·core 동일 검증을 포함한다. 기존 내장 6종과 미지정 문서는 자동 저장 없이 보존한다. 선택 icon에는 지원 lucide:name 또는 하나의 완전한 이모지를, iconColor에는 선택 HEX 색상을 저장한다. 색상은 Lucide에만 적용한다. 이미지 업로드·임의 SVG·외부 이미지 URL은 제외한다. 사용자 참고 이미지에 따라 이전 이모지 별도 입력칸을 없애고 아이콘 색상 선택을 범위에 추가한다. 완료 조건: 선택·검색·카테고리·색상, 저장·취소, 기존 문서 호환, 키보드·Esc·외부 클릭, 관련 검증 및 사용자 인수. 사용자 승인 전 doing 유지.
