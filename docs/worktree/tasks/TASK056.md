목적: 상세 참조를 이름으로 읽고 대상에 맞게 열 수 있게 한다. 범위: 이름·경로 편집과 이름 중심 목록, 웹·파일·폴더 아이콘, 웹 브라우저/파일 기본 앱/폴더 탐색기 열기 및 경로 복사. 완료 조건: 이름 없는 기존 참조도 기본 이름으로 표시하고 경로 확인이 가능하며 긴 값이 넘치지 않는다. 존재하지 않는 경로와 지원하지 않는 링크는 오류를 안내한다. 검증: 웹·로컬 파일·폴더·상대경로·공백/한글 경로·복사·저장/재조회. 공통 참조 규격 작업 결과를 사용하며 실제 의존 ID는 등록 후 연결한다. 참조 설명과 관련 이슈 연결은 제외한다.
